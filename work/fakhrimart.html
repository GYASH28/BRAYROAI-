01 / THE IDEA

From catalogue page
to sales surface.

The goal was not to decorate a wholesale website. It was to make product discovery, brand hierarchy, and enquiry feel clearer—while keeping the experience fast enough to work in the real world.

INTERFACE PROOF / REAL SCREENS

The design argument is visible in the shipped interface—not in presentation mockups.

02 / THE SYSTEM

01

Hierarchy first

Products, categories, and enquiry routes were given a clearer visual order so the interface communicates before it decorates.

02

Responsive by design

Desktop and mobile are treated as separate compositions, not the same layout squeezed into different widths.

03

Interaction with purpose

Motion and transitions are used to guide attention and pace instead of constantly asking to be noticed.
