01 / THE PRODUCT QUESTION

What if study tools felt like one system?

Lernio started as a practical attempt to reduce the jump between lessons, notes, practice, revision and planning. The product keeps those activities inside one shared learning context instead of treating each as a separate app.

This is studio work, not a client commission. It is included here because the live product and public repository provide inspectable evidence of product design, frontend engineering, AI integration and system thinking.

01 / LEARN

Curriculum-aware learning

Subject and lesson structure, interactive materials and resumable learning flows.

02 / PRACTICE

AI-supported study

LEO tutor, quizzes, exam practice, flashcards and multiple explanation modes.

03 / UNDERSTAND

Progress as feedback

Planner, readiness signals, subject performance and study analytics.

02 / WHAT WAS BUILT

A product with real surface area.

The repository documents a Next.js 16 / React 19 application with authentication, PostgreSQL data, Groq-backed AI services, curriculum content, practice and exam flows, spaced-repetition revision, coding tools, community features and role-based dashboards.

The point of this case is not to claim commercial outcomes. It is to show the depth of a system that can be opened, tested and inspected.
