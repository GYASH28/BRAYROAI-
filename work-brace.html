01 / THE PRODUCT QUESTION

Can AI context stay yours?

BRACE explores a simple problem: people work across many AI tools, but useful project context and decisions become fragmented. The product turns selected local material into one provenance-backed memory layer that compatible AI clients can recall.

It is self-initiated studio work rather than a client engagement. The public repository, release artifacts, documentation and screenshots make the implementation inspectable without inventing business outcomes.

01 / MEMORY

Evidence-backed recall

Structured memory, decisions, events, source evidence, search and explicit retention.

02 / CONNECTION

One layer across tools

MCP-compatible workflows for Codex, Claude Code and other stdio clients.

03 / CONTROL

Local-first boundaries

SQLite storage, permissioned setup, export, backup and explicit forgetting.

02 / WHAT WAS BUILT

Memory is useful when you can inspect it.

The current preview includes a desktop Brain workspace, capture inbox, evidence-aware recall, graph and timeline views, an Automation Studio, MCP tooling, hardened Electron boundaries and Windows/Linux packages.

The design work is therefore inseparable from system architecture: the interface has to make provenance, confidence, permissions and memory lifecycle understandable rather than hide them behind an AI chat box.
