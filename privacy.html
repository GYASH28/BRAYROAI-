PRIVACY / PLAIN LANGUAGE

Know what happens to the information you share.

BRAYROAI keeps the public website deliberately lightweight. This page describes the current website and enquiry flow; it does not claim data systems that are not actually configured.

What does the website collect automatically?

The current website does not include a BRAYROAI-operated account system or production CRM submission backend. The V21 interface can emit privacy-safe interaction events inside the browser so analytics can be connected later, but it does not send form contents into those events. Hosting and network providers may process normal request information such as IP address, browser information and requested URLs as part of operating the service.

What happens when I use the Growth Audit?

The Audit currently prepares a structured message from the information you enter. Nothing is represented as stored in a BRAYROAI database. You choose whether to send the prepared request using email or WhatsApp. Once you choose one of those services, the information is processed through that provider under its own terms and privacy practices.

What information can an Audit request contain?

It can include your name, work email, company, website, region, approximate implementation budget, selected priority and the workflow notes you provide. Do not include passwords, API keys, payment-card details or other secrets in the enquiry.

Does BRAYROAI sell visitor data?

BRAYROAI does not sell website enquiry data. If analytics or CRM infrastructure is added later, this page should be updated before those systems are treated as part of the public website.

What about client project data?

Access, data handling, third-party services, ownership and retention for paid client work should be defined in the applicable project scope or agreement because requirements vary by implementation.

How can I contact BRAYROAI about privacy?

Use the contact details published by BRAYROAI or email yashganesh.work@gmail.com with enough context to identify the relevant enquiry or project. Do not send account passwords or authentication secrets by email.
