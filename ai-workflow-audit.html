FAQ

The questions
worth asking.

Clear boundaries make the first engagement more useful.

01Do I need to know which AI tool I want?

No. The audit starts from the workflow and problem. Tool choice comes after the use case, data and constraints are understood.

02Will you access our systems during the audit?

Not by default. The base audit can be completed from a structured walkthrough, examples and agreed materials. Any direct system access is separately agreed and should use the minimum access needed.

03Is the audit fee refundable?

The ₹9,999 is payment for the audit work and deliverables. It is not a refundable deposit, but it is credited toward a subsequent BRAYROAI AI implementation when that build follows from the audit.

04What if the best answer is “do not use AI”?

That is a valid outcome. The audit is meant to prevent unnecessary tooling as much as it is meant to find useful opportunities.

05How long does it take?

The discovery itself is 60–90 minutes. The exact turnaround for the written action plan is confirmed when the audit is booked, based on workload and complexity.
